# libPVZ2 补丁参考：CDN LawnStrings skip · Glyph cache clear

面向 **PvZ2: Reflourished 1.4.2**（Android `arm64-v8a` `libPVZ2.so`）上的两处行为修复。  
本目录可直接打包分发：脚本与本文同级。

| 文件 | 作用 |
|------|------|
| `patch_cdn_lawnstrings_skip.py` | 联网 CDN 不覆盖本地 `LawnStrings-*` |
| `patch_glyph_cache_clear.py` | 字图集满时清全局 atlas 并重试一次排字 |
| `技术说明.md` | 本文（原理优先，便于移植） |

**打补丁顺序（安卓 SO）：** 先 CDN skip，再 Glyph clear。

**版本钉死：** 文中地址均为该版 ELF 中「VA ≈ 文件偏移（首个 LOAD）」的 guest 地址；换游戏版本须重找。

---

## 0. 移植时先抓住原理，再谈二进制

两份脚本是 **安卓 ELF 上的机器码补丁实现**，不是可直接贴到 iOS Mach-O 的补丁包。  
给 Darwin / 其它宿主移植时，优先复刻 **行为**，不必复刻 cave 字节：

| 能力 | 推荐落点 |
|------|----------|
| CDN skip | **宿主 CDN 层**过滤/拒写 `LawnStrings-*`（最干净） |
| Glyph clear | **游戏内**「atlas 满 → clear 全局 mesh → 重试 BuildPart」；可用 AOT 烤钩子，对齐 RFLib 钩子表思路 |

下面按「游戏本来怎么做 → 我们改什么」写。

## 1. CDN LawnStrings skip

### 1.1 问题

游戏会从官方 CDN 拉取 `1.4.2.main.tar`（gzip），再：

1. **Untar**：按成员名写出文件；  
2. **Apply**：把解出的文件应用到本地 CDN 目录。

其中 `LawnStrings-*`（尤其 `LawnStrings-en-us.rton`）是文案表。  
若本地已是中文 RTON，官方英文成员仍会被解出并应用 → **联网后中文被盖回英文**。其它 CDN 资源仍希望照常更新。

### 1.2 原理（与语言无关）

在「按文件名处理 CDN 成员」的两条路径上，对 **`LawnStrings-` 前缀** 做特殊处理：

1. **Untar：** 检测到 LawnStrings 成员时，把将要使用的名字改成丢弃名（实现里为 `._cdn_lawn_skip`），再继续读 tar。  
   - 目的：tar 流仍顺序消费完（不破坏解包状态），但不会以 LawnStrings 名落地。  
2. **Apply：** 若当前文件名是 LawnStrings 系列，**跳过**真正的 apply 正文。  
   - 目的：双保险，避免残留仍被写入有效路径。

**不变式：** 非 LawnStrings 的 CDN 内容行为与原版一致；仅文案文件不被官方包覆盖。

### 1.3 安卓参考实现（本目录脚本）

`patch_cdn_lawnstrings_skip.py` 在 `libPVZ2.so` 中：

- 钩 Untar 环一处、Apply 环一处，跳入 RX 区 NOP cave 中的壳代码；  
- 用游戏内已有格式串 `LawnStrings-%s` 做前缀/结构比对；  
- 写入丢弃名字符串并改名或跳过 apply。

关键地址（仅 1.4.2 安卓 SO，移植时勿照搬到 Mach-O）：见脚本顶部常量 `HOOK_UNTAR` / `HOOK_APPLY` / `LAWN_STR` / `CAVE_APPLY`。

```text
python patch_cdn_lawnstrings_skip.py path/to/libPVZ2.so
python patch_cdn_lawnstrings_skip.py path/to/libPVZ2.so --dry-run
```

### 1.4 移植建议（Darwin 等）

优先在宿主 CDN 管道（如下载回调、解压、写入 `No_Backup/CDN.1.4.2/` 之前）实现：

- 跳过写入任何 `LawnStrings-*`；或  
- 若本地已有文案且需保留汉化，则永不覆盖该类文件。

效果与 SO 补丁等价，且不依赖 guest 代码洞穴，版本升级成本更低。

## 2. Glyph cache clear

### 2.1 问题

CJK 量大时，`PrimeGlyphMesh_General::BuildPart` 往共享字图集里塞字形；**atlas 放不下**时，原版只打 WARNING 并给出空白度量。

后果常见：

- 图鉴/对话越翻越缺字、横杠；  
- HUD 仍引用旧 UV → 宝石、硬币等数字花屏。

### 2.2 原理（与语言无关）

字图集满不是「缺字体文件」，而是 **运行时 atlas 槽位耗尽**。需要的行为是：

1. 在 BuildPart **放不下字形、即将走警告路径**时介入；  
2. 取得 **全局** glyph mesh（不是只清局部状态）；  
3. 调用游戏自带的 **clear**（清 atlas，并递增 mesh 上的 **generation**）；  
4. HUD 等若缓存了该 generation，会因不匹配而重建网格（避免脏 UV）；  
5. 重置当前 BuildPart 的游标/绘制计数等，**回到字形循环再排一次**；  
6. **每个 BuildPart 调用最多重试一次**，第二次仍失败则回退原警告路径（防死循环）。

**不变式：** 不改字体资源本身；只在「满了」时清空共享 atlas 并允许当次排版重来一遍。

### 2.3 安卓参考实现（本目录脚本）

`patch_glyph_cache_clear.py`：

- BuildPart 入口处用栈槽作 retry 标志（实现用 `[sp,#0x70]`，选未占用槽）；  
- 钩警告点：未重试 → `get_global_mesh` → `clear` → 重置寄存器/draw count → 跳回 loop head；已重试 → 原警告路径；  
- cave 放在 CDN 补丁洞穴之后；洞穴内不对 RX 段做自修改存储。

关键地址见脚本：`HOOK_WARN` / `HOOK_ENTRY_NOP` / `GET_GLOBAL_MESH` / `CLEAR_MESH` / `LOOP_HEAD` / `CAVE_GLYPH`。

```text
# 须先完成 CDN skip
python patch_glyph_cache_clear.py path/to/libPVZ2.so
python patch_glyph_cache_clear.py path/to/libPVZ2.so --dry-run
```

### 2.4 移植建议（Darwin 等）

须在 **guest 字形逻辑**内实现（宿主 OpenGL 层一般碰不到这套 mesh）。可选：

- 在 ELF→Mach-O / 钩子烘焙阶段写入与上节相同的控制流；或  
- 用等价 hook 调游戏已有 `clear` + 重入 BuildPart 循环。

不要把安卓文件偏移直接当 Mach-O 偏移用；以符号/行为验证为准，地址需在目标镜像上重标定。

## 3. 验收（安卓上已验证过的信号）

**CDN skip**

- 推入中文 `LawnStrings-en-us.rton` 后强制联网刷新 CDN；  
- 该文件 MD5 不变；目录中可出现 `._cdn_lawn_skip`；  
- 文案保持中文，其它活动资源仍可更新。

**Glyph clear**

- 快速翻大量图鉴/含稀有汉字的界面；  
- 不应持续恶化为缺字；货币等 HUD 数字不应因翻图鉴而花屏。

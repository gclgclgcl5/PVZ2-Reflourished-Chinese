# PvZ2 Reflourished（返茂）1.4.2 完整汉化教程

本文说明如何把 **Plants vs. Zombies 2 Reflourished 1.4.2**（包名 `com.ea.game.pvz2_rfl`）做成可联网保持中文的汉化包，并达到与本仓库实测相同的效果：

- 联网后 UI / 图鉴 / 剧情仍为中文（CDN 不被英文覆盖）  
- **对话气泡可显示中文**（不再是横杠 ▯▯▯）  
- OBB + CDN 文案一致，断网/联网均可玩  

返茂作者已声明允许汉化；请勿用于商业倒卖。

---

## 0. 先搞清：文案与字体从哪里来

| 来源 | 路径 / 资源 | 是否必须汉化 | 说明 |
|------|-------------|--------------|------|
| OBB | `main.675.com.ea.game.pvz2_rfl.obb` 内 `Packages` → `LawnStrings*.rton` | 是 | 离线/首次资源；本版 RSG 为 **zstd** |
| OBB | 同包内 `Packages` → `NPCDataSheet` 等 | **是（对话可读）** | 对话用的 `FontName`（如 `PICO_30`）指向**无中文字形**的拉丁体 |
| OBB | `LoadingFonts` RSG | 建议改 | 把 `BrianneTod` 别名到已有中文 UI 字体 `fbUsv8C5eI` |
| CDN | `/sdcard/Android/data/com.ea.game.pvz2_rfl/files/No_Backup/CDN.1.4.2/LawnStrings-en-us.rton` | **是（关键）** | 联网后优先读这里；官方英文会覆盖 OBB |
| APK | `lib/arm64-v8a/libPVZ2.so` | 是（补丁） | 阻止 CDN 再覆盖 `LawnStrings-*` |
| APK | `res/values/strings.xml` 等 | 可选 | 桌面名等壳文案 |

**只改 OBB 里的 LawnStrings 不够。** 完整方案是：

1. 翻译并回封 OBB 的 LawnStrings（×6）  
2. **把对话字体映射到带中文的 `BLACK_*`，并别名 BrianneTod**（否则对话横杠）  
3. 准备中文 `LawnStrings-en-us.rton` 推到 CDN 目录  
4. **补丁 `libPVZ2.so`**：CDN 解压时跳过真正的 `LawnStrings-*`  

联网刷新任务/配置仍正常，中文 LawnStrings 不会被覆盖；对话也能出字。

### 1.4.2 OBB 关键常量（原地补丁用）

| 项 | 值 |
|----|-----|
| OBB 文件名 | `main.675.com.ea.game.pvz2_rfl.obb` |
| OBB 原大小 | `1341358080` 字节（勿随意截断/加长，除非改 RSB 索引） |
| Packages 压缩数据偏移 | `0xCF55000` |
| Packages 压缩槽大小 `csize` | `3522560` |
| Packages zstd 帧头 Descriptor | **`0x80`**（非 single-segment） |
| LoadingFonts 组数据偏移 | `0xB17B000` |
| 启动 Activity | `com.ea.game.pvz2_rfl/com.popcap.PvZ2.PvZ2GameActivity` |

## 2. 提取英文 LawnStrings 与 Packages 段

### 2.1 从 OBB 取出 Packages 中的 RTON

OBB 是 RSB（`1bsr`）。`Packages` 数据段为 **zstd**（魔数 `28 B5 2F FD`），旧 zlib 工具会失败。

可用两种方式：

**A. Sen 工程（推荐整包改）**

```powershell
cd F:\othergit\Reverse Engineer Anything\tools\Sen
# 把 OBB 拷到 F:\sen_work\ 短路径后再操作
.\Launcher.exe -method popcap.rsb.init_project
# 按提示选择 OBB，生成工程后在资源里找到 LawnStrings*.rton
```

**B. 本仓库已提取的原文**

直接使用：

- `localization/LawnStrings_en.json`（约 26637 条）  
- `localization/LawnStrings_en.rton`

用脚本从 RTON 导出 JSON（若你有新的 RTON）：

```powershell
python localization\scripts\extract_lawnstrings.py path\to\LawnStrings.rton -o localization\LawnStrings_en.json
```

### 2.2 解出 `packages_section.bin`（原地补丁必做）

从 OBB 的 Packages 槽解压整段：

```powershell
python -c @"
from pathlib import Path
import zstandard as zstd
obb = Path(r'F:\sen_work\main.675.com.ea.game.pvz2_rfl.obb').read_bytes()
PACK_OFF, CSIZE = 0xCF55000, 3522560
raw = zstd.ZstdDecompressor().decompress(obb[PACK_OFF:PACK_OFF+CSIZE])
Path(r'F:\sen_work\packages_section.bin').write_bytes(raw)
print('section', len(raw))
"@
```

之后所有 LawnStrings / 对话字体修改都基于这份 `packages_section.bin`。

### 2.3 结构说明

游戏读的是 RTON 对象里的 **`LocStringValues`**：交替的 key / value 字符串数组。  
汉化时只改 value，**不要改 key**，也不要打乱顺序。

## 3. 翻译

### 3.1 基础流程

1. 复制英文 JSON 为 `LawnStrings_zh.json`（或沿用本仓库已有译文）  
2. 只翻译 value  

原则：

- 专有名词前后一致（植物名、僵尸名、模式名）  
- 保留 `%s`、`{0}`、换行、颜色标记等占位符  
- 未译条目可暂时保留英文  

查看进度：`localization/progress.json`；质量抽检：`python localization\scripts\qa_translations.py`。

### 3.2 推荐：合并 ParaTranz 参考译（大幅提升覆盖）

本仓库提供社区参考：`localization/参考翻译/utf8/LawnStrings-ParaTranz.json`。

```powershell
python localization\scripts\merge_ref_paratranz.py
# 可选再合并风格向条目：
# python localization\scripts\merge_ref_p2.py
```

说明：

- **P0**：同 key 且原文匹配 → 用参考译覆盖  
- **P1**：英文文本相同、key 不同（如成就命名差异）→ 写入返茂 key  
- 合并后应用 `qa_translations.py` 抽查；例如土豆地雷相关键应能看到「砰隆」「给力」等参考用词  

### 3.3 外部 AI 分批翻译（可选）

```powershell
python localization\scripts\export_all_for_ai.py
# 译完得到 batch_XXX.zh.json 后：
python localization\scripts\import_ai_translations.py --dir localization\export_for_ai
```

**不要**对已整句汉化的库再跑整库 `apply_translation.py` 短语替换，以免污染译文。

## 5. 回封 OBB：LawnStrings + 对话字体（完整效果必做）

只替换 LawnStrings 会出现：**菜单/图鉴中文，对话气泡横杠**。  
完整汉化必须再做 **第 5.2 节对话字体兼容**。

### 5.1 替换 Packages 内 6 份 LawnStrings

1.4.2 的 `packages_section.bin` 里有 **6 份相同** 的 LawnStrings：

| 偏移 | 槽大小 |
|------|--------|
| 1540096, 4206592, 6873088, 9539584, 12206080, 14872576 | 各 2666496 字节 |

```powershell
python localization\scripts\repack_obb_packages.py `
  F:\sen_work\packages_section.bin `
  F:\sen_work\LawnStrings_zh.rton `
  F:\sen_work\packages_section_zh.bin `
  --out-zstd F:\sen_work\packages_zh.zst
```

### 5.2 对话字体 → `BLACK_*`（解决横杠）

#### 现象与原因

| 现象 | 原因 |
|------|------|
| 戴夫 / Penny / 其他 NPC 对话是横杠或空白 | `NPCDataSheet` 等里的 `FontName` 指向 `BRIANNE_*` / `PICO_*` / `ASHLEY_*` 等拉丁体，**字形里没有汉字** |
| UI「点击继续」正常、对话不正常 | UI 用的是 `BLACK_*` → 底层 `fbUsv8C5eI`（已有中文）；对话没用这套 |

#### 推荐做法（本仓库已验证、稳定）

用 `patch_dialogue_font_compat.py` 一次性完成：

1. 把 NPC / 额外对话框里的拉丁字体名 **就地改写成更短的 `BLACK_*`**（RTON 字符串缩短后尾部补零，槽位长度不变）  
2. 用 streaming L19 zstd 重压 Packages  
3. 写入 OBB 的 `0xCF55000` 槽  
4. 在 `LoadingFonts` 目录里把 **BrianneTod** 的偏移/大小改成指向 **fbUsv8C5eI**（双重保险）

```powershell
python localization\scripts\patch_dialogue_font_compat.py `
  --section F:\sen_work\packages_section_zh.bin `
  --out-section F:\sen_work\packages_section_zh_black.bin `
  --out-zstd F:\sen_work\packages_final_black.zst `
  --obb F:\sen_work\main.675.com.ea.game.pvz2_rfl.obb `
       "F:\othergit\Reverse Engineer Anything\release_zh\main.675.com.ea.game.pvz2_rfl.obb"
```

主要映射（脚本内写死，1.4.2）：

| 原 FontName | 目标 |
|-------------|------|
| `BRIANNE_CONVERSATION_32/36` | `BLACK_32` / `BLACK_36` |
| `PICO_30` / `PICO_34` | `BLACK_28` / `BLACK_32` |
| `ASHLEY_36`、各类 BB/Rockwell/…_36 | `BLACK_36` 等 |
| 额外槽 `BRIANNE_32` | `BLACK_32` |

效果取舍：对话统一用 UI 黑体风格，**不再区分角色花体**，但中文稳定可读。这是当前推荐的「与本仓库一致」方案。

#### 若脚本只压了 zst、未写进 OBB

可手动写入（长度必须正好 `3522560`，不足则尾部补 `0`）：

```powershell
python -c @"
from pathlib import Path
PACK_OFF, SLOT = 0xCF55000, 3522560
zst = Path(r'F:\sen_work\packages_final_black.zst').read_bytes()
assert len(zst) == SLOT
for p in [
  Path(r'F:\sen_work\main.675.com.ea.game.pvz2_rfl.obb'),
  Path(r'F:\othergit\Reverse Engineer Anything\release_zh\main.675.com.ea.game.pvz2_rfl.obb'),
]:
    data = bytearray(p.read_bytes())
    assert len(data) == 1341358080
    data[PACK_OFF:PACK_OFF+SLOT] = zst
    p.write_bytes(data)
    print('ok', p)
"@
```

### 5.3 zstd 注意（极易踩坑 → 开局闪退）

原版 Packages 压缩帧特征：

- 魔数 `28 B5 2F FD`  
- Frame Header Descriptor **`0x80`**（**非** single-segment）  
- 推荐：`compressobj` + **level 19** + `write_content_size=True`（见 `repack_obb_packages.compress_packages_zstd`）

错误压成 single-segment（常见 `0xA0`）可能导致游戏 **SIGSEGV / 闪退**。

若压缩结果比原 `csize`（`3522560`）更大，不能硬塞原地槽，请改用 **Sen 整包 `build_project` / pack** 重建 OBB。

### 5.4 不要做：自制「分角色 CJK 花体」LoadingFonts（当前会闪退）

曾尝试：`build_dialogue_cjk_fonts.py` + `rebuild_loadingfonts_rsg.py`  
把各拉丁体替换成改过 name 表的开源 CJK 字体，并追加/改写 LoadingFonts RSG。

**实测结果：打开游戏立刻闪退。**

原因概要：LoadingFonts 的 **UTF-32 路径名池 / 偏移表** 与游戏解析约定不一致时，字体加载阶段直接崩溃。  
在名称池编码完全对齐并验证前，**请不要**把自制 LoadingFonts 打进发布 OBB。

若已经打坏：

1. 从**原版** OBB 恢复 `0xB17B000` 处 LoadingFonts 数据与目录元数据（Brianne 条目回到 `off=0x1d000 size=0xea2c`）  
2. 保留你已改好的 Packages（中文 LawnStrings + `BLACK_*` 映射）  
3. 再推 OBB 启动验证  

救急：只用第 5.2 节的 `patch_dialogue_font_compat.py`，不要动 LoadingFonts 整包重建。

### 5.5 安装路径

```text
/sdcard/Android/obb/com.ea.game.pvz2_rfl/main.675.com.ea.game.pvz2_rfl.obb
```

`obbVersion` 需与游戏期望一致（如 `1.4.2-r01`）。版本不对时游戏会重新下官方 OBB，冲掉你的汉化。

## 6. 修改 APK：CDN 防覆盖补丁（联网中文的关键）

### 6.1 解码 APK

```powershell
apktool d "PvZ2 Reflourished 1.4.2.apk" -o work\apk_decoded
```

可选：改桌面名 `work/apk_decoded/res/values/strings.xml` 中 `app_name` → `植物大战僵尸2：返茂`。

### 6.2 打 libPVZ2.so 补丁

仅验证过 **返茂 1.4.2 arm64-v8a**。其他版本偏移会变，不能盲打。

```powershell
python localization\scripts\patch_cdn_lawnstrings_skip.py `
  work\apk_decoded\lib\arm64-v8a\libPVZ2.so
```

补丁逻辑：

1. **Untar（`0x16ad6c8`）**：成员名以 `LawnStrings-` 开头 → 写到 `._cdn_lawn_skip`，不覆盖真正的 `LawnStrings-en-us.rton`  
2. **Applying（`0xd17c30`）**：文件名以 `LawnStrings-` 开头 → 跳过写盘  

脚本会在首次运行时备份为 `libPVZ2.so.bak_pre_lawnskip`。

### 6.3 重打包并签名

```powershell
apktool b work\apk_decoded -o F:\sen_work\PvZ2_RFL_zh_unsigned.apk

$bt = "$env:LOCALAPPDATA\Android\Sdk\build-tools\35.0.0"
& "$bt\zipalign.exe" -f -p 4 F:\sen_work\PvZ2_RFL_zh_unsigned.apk F:\sen_work\PvZ2_RFL_zh_aligned.apk
& "$bt\apksigner.bat" sign --ks F:\sen_work\debug.keystore --ks-key-alias androiddebugkey --ks-pass pass:android --key-pass pass:android --out F:\sen_work\PvZ2_Reflourished_1.4.2_zh.apk F:\sen_work\PvZ2_RFL_zh_aligned.apk
& "$bt\apksigner.bat" verify --verbose F:\sen_work\PvZ2_Reflourished_1.4.2_zh.apk
```

1. **联网**打开标题屏，主按钮为「开始」而非 `Start`  
2. 进关 / 剧情：**戴夫、Penny 等对话为中文汉字**，不是横杠  
3. 图鉴抽查植物描述（如土豆地雷）与参考译一致  
4. 强制 CDN 刷新后（删掉 `Quests.rton` 等再启动），`Quests` 会恢复，但：

## 8. 原理简述（给要改版/移植的人）

```text
启动 → ContentDownloader
        ↓
   下载 main.tar（CDN: reflourished.ducnguyen.org 一类地址在 libRFLib）
        ↓
   Extracting TAR  (libPVZ2: 0x141d590 → 0x16ad6c8 → 0x16afaf8)  ← 真正写 LawnStrings
        ↓
   Applying file… (0xd17c30 → 0xd18174 / 0xd187a8)                 ← 后处理
        ↓
   UI 通过格式串 "LawnStrings-%s" 加载 CDN.1.4.2 下的 locale 文件

对话气泡：
   NPCDataSheet.FontName → typefaces 名称（BRIANNE/PICO/…）
        ↓
   LoadingFonts 内对应 TTF
        ↓
   无 CJK → 缺字形显示为横杠
   解决：FontName 改 BLACK_*（fbUsv8C5eI）+ 可选 BrianneTod 别名
```

补丁对准 **1.4.2 arm64** 固定偏移；换版本需重新找：

- 字符串 `LawnStrings-%s`、`Applying file`、`Extracting TAR file`  
- untar 循环里 `bl 0x16af178`（取成员名）之后  
- apply 循环里取文件名之后、按 type 分发之前  
- Packages / LoadingFonts / NPCDataSheet 在 RSB 中的新偏移

|------|------|------|
| 安装后仍全英文 | CDN 英文覆盖 / 未推中文 RTON | 推送中文 `LawnStrings-en-us.rton` + 确认 SO 补丁 |
| 仅断网中文 | 未打 CDN 补丁 | 重新 patch `libPVZ2.so` 并重签安装 |
| **菜单中文、对话横杠** | 对话字体无 CJK | 跑 `patch_dialogue_font_compat.py` 后重推 OBB |
| **打开就闪退** | Packages zstd 帧格式错（single-segment） | 用 streaming L19、desc=`0x80`；见 `compress_packages_zstd` |
| **打开就闪退** | 自制 LoadingFonts / 错误名称池 | **恢复原版 LoadingFonts**；只用 BLACK 映射方案 |
| **打开就闪退** | Packages 压缩体大于槽或写错偏移 | 确认写在 `0xCF55000`、长度 `3522560`、OBB 总长不变 |
| 游戏重新下官方 OBB | obb 文件名/版本不匹配 | 使用 `main.675.…` 且版本与 APK 一致 |
| Sen 报错 / 卡住 | 路径含空格、中文 | 全部放到 `F:\sen_work` |
| `patch_cdn_*.py` 报 unexpected bytes | SO 版本不对或已补丁 | 用原版 1.4.2 的 so，或从 `.bak_pre_lawnskip` 恢复 |
| 清了 CDN 目录又变英文 | 没有中文种子文件 | 再 push 一次中文 RTON；补丁不会自动注入译文 |
| 参考译没进游戏（如「砰隆」） | 只改了 JSON 未 encode/回封，或 CDN 仍是旧 RTON | 重新 encode → 回封 OBB → **同步推 CDN** |
| 只改了 OBB、CDN 仍旧译 | 两套文案不同步 | OBB 与 `LawnStrings-en-us.rton` 用同一份 RTON |
| Activity 不存在 | 启动组件名写错 | 用 `com.popcap.PvZ2.PvZ2GameActivity` |
| 32 位设备 | 本补丁只改了 arm64-v8a | 需对 `armeabi-v7a` 另找偏移再打 |

## 10. 最小复现清单（给发布者）

发给别人时至少包含：

1. `PvZ2_Reflourished_1.4.2_zh.apk`（含 CDN 补丁的签名包）  
2. `main.675.com.ea.game.pvz2_rfl.obb`（Packages：**中文 LawnStrings + BLACK 对话字体映射**；LoadingFonts：原版或仅 Brianne 别名）  
3. `LawnStrings-en-us.rton`（与 OBB 同一份中文，安装后 push 到 CDN 目录）  
4. 本文或简短安装说明（第 7 节）

本仓库 `release_zh/` 即为上述三件套示例。

## 11. 推荐工作流小结

```text
译 / 合并 LawnStrings_zh.json
        ↓ Sen encode
LawnStrings_zh.rton  ──┬──→ 复制为 CDN 用 LawnStrings-en-us.rton
                       └──→ repack_obb_packages（×6）
                                ↓
                       packages_section_zh.bin
                                ↓
                       patch_dialogue_font_compat.py
                       （FontName→BLACK_* + zstd + 写入 OBB + Brianne 别名）
                                ↓
                       汉化 OBB
apktool d
        ↓ patch_cdn_lawnstrings_skip.py
libPVZ2.so
        ↓ apktool b + zipalign + apksigner
汉化 APK
        ↓ adb install + 推 OBB + 推 CDN RTON
验收：标题「开始」+ 对话汉字 + 联网不回英文
```

**不要**把未验证的 `rebuild_loadingfonts_rsg` 产物打进发布包。

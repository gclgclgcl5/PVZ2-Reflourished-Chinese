# PvZ2 Reflourished（返茂）1.4.2 完整汉化教程

本文说明如何把 **Plants vs. Zombies 2 Reflourished 1.4.2**（包名 `com.ea.game.pvz2_rfl`）做成可联网保持中文的汉化包，并达到与本仓库实测相同的效果：

- 联网后 UI / 图鉴 / 剧情仍为中文（CDN 不被英文覆盖）  
- **图鉴植物属性行**（如「阳光产出速率」「禅境加持」）为中文，而非英文原句  
- **对话气泡完整中文**（无 `_` / 横杠缺字；发布可用多风格字）  
- OBB + CDN 文案一致，断网/联网均可玩  

返茂作者已声明允许汉化；请勿用于商业倒卖。

---

## 0. 先搞清：文案与字体从哪里来

| 来源 | 路径 / 资源 | 是否必须汉化 | 说明 |
|------|-------------|--------------|------|
| OBB | `main.675.com.ea.game.pvz2_rfl.obb` 内 `Packages` → `LawnStrings*.rton` | 是 | 离线/首次资源；本版 RSG 为 **zstd** |
| OBB | 同包内 `Packages` → 植物属性 **ASCII 字面量** | **是（图鉴属性完整）** | 大量标题/加持值是 `0x90` 英文，不是 `[STAT_…]`；见 **§5.1.1** |
| OBB | 同包内 `Packages` → 关卡 `StarChallengeBeatTheLevelProps` **目标 Description** | **是（过关要求完整）** | 正文常为 `0x90` 英文句，不是 `STARCHALLENGE_*` 键；见 **§5.1.2** |
| OBB | 同包内 `Packages` → `NPCDataSheet` 等 | **是（对话可读）** | 对话用的 `FontName`（如 `PICO_30`）指向**无中文字形**的拉丁体 |
| OBB | `LoadingFonts` + FontName | **是（对话可读）** | **发布推荐**：方案 A `--full-coverage` 多风格 CJK；**一键复刻默认**：`BLACK_*` 保底 |
| CDN | `/sdcard/Android/data/com.ea.game.pvz2_rfl/files/No_Backup/CDN.1.4.2/LawnStrings-en-us.rton` | **是（关键）** | 联网后优先读这里；官方英文会覆盖 OBB；**运行时图鉴也读这份** |
| APK | `lib/arm64-v8a/libPVZ2.so` | 是（补丁） | 阻止 CDN 再覆盖 `LawnStrings-*` |
| APK | `res/values/strings.xml` 等 | 可选 | 桌面名等壳文案 |

**只改 OBB 里的 LawnStrings 不够。** 完整方案是：

1. 翻译并回封 OBB 的 LawnStrings（×6）  
2. **图鉴植物属性（§5.1.1）**：Packages 内英文属性字面量 → 等长 `[STAT_…]`，中文写入 LawnStrings  
3. **关卡过关要求（§5.1.2）**：Packages 内目标 Description 英文 → 等长 `[OBJ_…]`，中文写入 LawnStrings  
4. **对话字体**：**自己发布**用方案 A（LoadingFonts 全字符集多风格字，§5.2）；**一键复刻**默认 BLACK 保底  
5. 准备中文 `LawnStrings-en-us.rton` 推到 CDN 目录（与 OBB **同一份**，含图鉴/目标新键）  
6. **补丁 `libPVZ2.so`**：CDN 解压时跳过真正的 `LawnStrings-*`  

联网刷新任务/配置仍正常。一键路径见 [复刻最短路径.md](./复刻最短路径.md)。

## 2. 提取英文 LawnStrings 与 Packages 段

### 2.1 从 OBB 取出 Packages 中的 RTON

OBB 是 RSB（`1bsr`）。`Packages` 数据段为 **zstd**（魔数 `28 B5 2F FD`），旧 zlib 工具会失败。

推荐直接使用本仓库已提取的原文，或用自研脚本从 RTON 导出：

- `localization/LawnStrings_en.json`（约 26637 条）  
- `localization/LawnStrings_en.rton`

```powershell
python localization\scripts\extract_lawnstrings.py path\to\LawnStrings.rton -o localization\LawnStrings_en.json
# 等价：python localization\scripts\lawnstrings_rton.py decode path\to\LawnStrings.rton -o …
```

### 2.2 解出 `packages_section.bin`（原地补丁必做）

偏移与槽长集中在 `localization/scripts/obb_layout_142.py`（`PACKAGES_OFF` / `PACKAGES_CSIZE`）。抽写用该模块 CLI，勿再手写 `python -c`：

```powershell
python localization\scripts\obb_layout_142.py extract `
  F:\sen_work\main.675.com.ea.game.pvz2_rfl.obb `
  -o F:\sen_work\packages_section.bin

# 改完 section 后写回（自动 zstd L19 + 补零到 csize）：
python localization\scripts\obb_layout_142.py write `
  F:\sen_work\main.675.com.ea.game.pvz2_rfl.obb `
  F:\sen_work\packages_section_zh.bin `
  -o F:\sen_work\main_zh.obb
```

一键整条流水线（STAT/OBJ/LawnStrings/BLACK → 汉化 OBB + CDN RTON）见 **[复刻最短路径.md](./复刻最短路径.md)**。

之后所有 LawnStrings / 对话字体修改都基于这份 `packages_section.bin`。

### 2.3 结构说明

游戏读的是 RTON 对象里的 **`LocStringValues`**：交替的 key / value 字符串数组。  
汉化时只改 value，**不要改 key**，也不要打乱顺序。

### 5.1.1 图鉴植物属性字面量（必做才完整）

#### 现象与原因

只汉化 LawnStrings 后，图鉴里常见：

| 现象 | 原因 |
|------|------|
| 属性行仍是英文（如 `SUN PRODUCTION RATE`、`ZEN GARDEN BOOST`、`x3 Toughness`） | Packages 植物属性里大量标题/加持值是 **RTON `0x90` ASCII 字面量**，不是 `[STAT_SUNCOST]` 这类查表键 |
| 改成中文后整行变横线 / `_` | **禁止**把 UTF-8 中文直接塞进 `0x90` 槽：图鉴 UI 按拉丁字形渲染，缺字即横线 |
| `<Missing STAT_…>` | Packages 已改成 `[STAT_…]`，但 **CDN 的 LawnStrings 没有这些新键**（或仍是旧 RTON） |
| 正文突然变回机翻 | 误用了已归档的 `LawnStrings_sen_zh.json` 等机翻底整库覆盖 |
| `生命值_3` 一类怪字 | `×`（U+00D7）等符号不在当前 CJK 字体里，显示成 `_`；译文里宜写 `x3` / `3倍` |

已有键如 `[STAT_SUNCOST]` →「阳光消耗」走 LawnStrings，所以部分行早就中文；**未改字面量的行才会漏英文**。

#### 正确做法：等长 `[STAT_…]` + LawnStrings

1. 在 Packages 里把英文改成 **与原文等长** 的 `[STAT_xxx]`（保持 `0x90` + 长度字节不变）  
2. 在 LawnStrings 里增加对应键的中文  
3. 回封 OBB Packages，并 **同步推 CDN**（运行时优先读 CDN）  
4. **强停再开**游戏（否则仍用内存里旧文案）

脚本：`localization/scripts/patch_packages_almanac_literals.py`  
（内置常见属性/加持译表；`--stat-refs` 自动生成等长键名。）

### 5.1.2 关卡过关要求字面量（选植物弹窗「关卡目标」正文）

| 现象 | 原因 |
|------|------|
| 标题已是「关卡目标」，正文仍是英文（如 `Survive and protect the endangered plants`） | 关卡 `StarChallengeBeatTheLevelProps` 的 **Description** 多为 RTON `0x90` 英文句；`STARCHALLENGE_*` 虽已汉化，但关卡未引用键名 |
| `<Missing OBJ_…>` | Packages 已改成 `[OBJ_…]`，但 CDN / OBB 的 LawnStrings 缺新键 |

处理：与图鉴属性相同——等长 `[OBJ_…]` + 中文写入 LawnStrings（**禁止**把 UTF-8 中文直接塞进 `0x90`）。

```powershell
python localization\scripts\patch_packages_objective_literals.py `
  F:\sen_work\packages_section_almanac_stat_lawn.bin `
  -o F:\sen_work\packages_section_objectives.bin `
  --lawnstrings-en localization\LawnStrings_en.json `
  --lawnstrings-zh localization\LawnStrings_zh.json `
  --keys-out localization\objective_keys.json
```

随后把 `objective_keys.json` 放进 `localization/`，跑 `python localization\scripts\build_zh_rton.py`（会自动合并 OBJ 键并编码）→ `repack_obb_packages` 注入 → 写回 OBB Packages 槽，并 **同步 CDN** `LawnStrings-en-us.rton`（流程同 §5.1.1 ③–⑤）。键表见仓库 `localization/objective_keys.json`。

**CDN 活动关**（`CDN.*/levels/**`，如末日草坪）也会写死英文 Description，但联网会重拉覆盖，**不适合作为发布管线**。正式包只保证 **OBB Packages 内本地关** 的 `[OBJ_…]`；活动关若要永久中文，需另做运行时拦截或改拉包逻辑（尚未做）。

#### 操作步骤（图鉴属性）

**① 底稿必须是现行优化译文，不要用早期机翻底整库覆盖**

权威文案：`localization/LawnStrings_zh.json`（及 `localization/current/`）。  
**不要**使用已归档的 `LawnStrings_sen_zh.json` 等机翻底整库重编。

**② 打 Packages 属性字面量，并导出新键**

以「只换过 LawnStrings、尚未改属性」的段为输入（例如 `packages_section_zh.bin`）：

```powershell
cd F:\othergit\Reverse Engineer Anything

python localization\scripts\patch_packages_almanac_literals.py `
  F:\sen_work\packages_section_zh.bin `
  -o F:\sen_work\packages_section_almanac_stat.bin `
  --stat-refs `
  --keys-out localization\almanac_stat_keys.json
```

- `--stat-refs`：英文 → `[STAT_…]`（正确路径）  
- 不加该开关会尝试「中文塞进 `0x90`」，**实测会出横线，不要用于发布**  
- 抽查：原 `ZEN GARDEN BOOST` 应变为等长 token（如 `[STAT_ZEN_GARDE]`），且仍为 `0x90` 前缀  

**③ 合并新键并自研 encode**

把导出的 `almanac_stat_keys.json` 放进 `localization/`（或已在该路径），然后：

```powershell
cd F:\othergit\Reverse Engineer Anything\localization\scripts
python build_zh_rton.py
# 自动合并 STAT_/OBJ_ 键 → encode → current/LawnStrings_zh.rton
```

检查：`LawnStrings_zh.rton` **≤ 2666496**；用 `extract_lawnstrings.py` / `lawnstrings_rton.py decode` 确认新键存在（如禅境加持），且旧键仍是参考译（如 `STAT_SUNCOST` =「阳光消耗」而非「太阳成本」）。  
译文忌用 `×` 等易缺字符号（例如写成「生命值x3」）。

**④ 把新 RTON 注入 Packages，再写入 OBB**

```powershell

  F:\sen_work\packages_section_almanac_stat.bin `
  F:\sen_work\LawnStrings_zh.rton `
  F:\sen_work\packages_section_almanac_stat_lawn.bin `
  --out-zstd F:\sen_work\packages_almanac_stat.zst
```

将压缩结果写入 OBB 的 Packages 槽（见 `obb_layout_142.py`：`PACKAGES_OFF` / `PACKAGES_CSIZE`）：


#### 补漏 / 扩表

脚本内 `TRANSLATIONS` 已覆盖常见 ALL-CAPS 属性与加持值（如 `-50 Sun Cost`、`x2 Toughness`）。若某植物仍有英文：

1. 在 `packages_section_zh.bin` 里搜该英文（须为 `0x90` + 长度前缀）  
2. 在 `TRANSLATIONS` 增加「英文 → 中文」  
3. 从 **未打属性补丁** 的 `packages_section_zh.bin` 重新跑 ②～⑤（避免在已替换的 `[STAT_…]` 上再找英文）  

#### 验收

- 向日葵：有「阳光产出速率」「禅境加持」等中文，无 `<Missing …>`、无横线  
- 玉米投手等：黄油相关行应为完整中文（如「黄油伤害」），而非残留英文  
- 强停再开后正文仍是参考译（抽查「阳光消耗」「冷却时间」「生命值」）

### 5.2 对话字体

#### 现象与原因

| 现象 | 原因 |
|------|------|
| 对话横杠 / `_` 缺字 | `FontName` 指向拉丁 TTF，或 CJK 子集未覆盖该字 |
| 同一句忽粗忽细 | 主字体缺字 → 引擎回退到另一套字体 |
| UI「轻点以继续」正常 | UI 走 `fbUsv8C5eI` |

#### 方案 A（**你自己发布推荐**：多风格字）

硬性约束（1.4.2）：LoadingFonts **`usize` 固定 `0x4B7000`，禁止增大**；字符集须覆盖整份 `LawnStrings_zh.json`；Packages 先保留原 FontName（不要先跑 BLACK）。

```powershell
# 1) 从 fonts_src 做全字符集 fonts_cjk（name 表保持游戏原字体名）
python localization\scripts\build_dialogue_cjk_fonts.py

# 2) Packages：中文 LawnStrings，仍保留原 FontName
python localization\scripts\repack_obb_packages.py `
  packages_section.bin LawnStrings_zh.rton packages_section_zh.bin

# 3) 写入底座 OBB 后打 LoadingFonts
python localization\scripts\patch_loadingfonts_append.py `
  --stock-obb 原版.obb `
  --base-obb 已换Packages的底座.obb `
  --fonts-dir F:\path\fonts_cjk `
  --full-coverage `
  --out-obb 发布用汉化.obb
```

辅助：`inspect_loadingfonts.py` 看名池。**禁止** `rebuild_loadingfonts_rsg.py`（整表重写易闪退）。

#### 保底 / 一键复刻（`BLACK_*`）

外人最短路径、或不想维护 fonts_cjk 时：FontName→`BLACK_*`。`reproduce_zh.py` **默认走这条**，对话统一黑体但可读。

```powershell
python localization\scripts\patch_dialogue_font_compat.py `
  --section packages_section_zh.bin `
  --out-section packages_section_zh_black.bin `
  --out-zstd packages_final_black.zst `
  --obb 原版或底座.obb
```

**注意**：方案 A 的 OBB **不要**再叠一层 BLACK（会丢掉分角色字体）。

### 5.3 zstd 注意（极易踩坑 → 开局闪退）

原版 Packages 压缩帧特征：

- 魔数 `28 B5 2F FD`  
- Frame Header Descriptor **`0x80`**（**非** single-segment）  
- 推荐：`compressobj` + **level 19** + `write_content_size=True`（见 `repack_obb_packages.compress_packages_zstd`）

错误压成 single-segment（常见 `0xA0`）可能导致游戏 **SIGSEGV / 闪退**。

若压缩结果比原 `csize`（`3522560`）更大，不能硬塞原地槽：先提高 zstd 等级/减少新增键体积；仍超限则需另做完整 RSB 重建工具（本仓库日常流程不覆盖）。

### 5.4 LoadingFonts 踩坑（方案 A）

| 做法 | 结果 |
|------|------|
| `rebuild_loadingfonts_rsg.py` 整表重写 | 闪退 |
| 增大 `usize` / 末尾乱追加 | 闪退 |
| **固定 `0x4B7000` + `--full-coverage`** | 发布推荐 |
| Top-N 子集 | 能开但大量 `_` |
| 仅 BLACK 映射 | 可启动，无分角色风格 |

打坏：用原版 OBB 重做方案 A，或临时回退 BLACK。

### 5.5 安装路径

```text
/sdcard/Android/obb/com.ea.game.pvz2_rfl/main.675.com.ea.game.pvz2_rfl.obb
```

`obbVersion` 需与游戏期望一致（如 `1.4.2-r01`）。版本不对时游戏会重新下官方 OBB，冲掉你的汉化。

## 6. 修改 APK：CDN 防覆盖补丁（联网中文的关键）

**一键（推荐）**：原版 1.4.2 APK → 已打 CDN skip + Glyph 并签名的汉化包，见 [复刻最短路径.md](./复刻最短路径.md) 与：

```powershell
python localization\scripts\reproduce_zh_apk.py --apk "原版.apk" --out-dir F:\out_zh
# 或 GUI：python localization\scripts\reproduce_zh_gui.py →「开始打 APK」
```

以下为等价手工步骤（排错用）。

### 6.1 解码 APK

```powershell
apktool d "PvZ2 Reflourished 1.4.2.apk" -o work\apk_decoded
```

可选：改桌面名 `work/apk_decoded/res/values/strings.xml` 中 `app_name` → `植物大战僵尸2：返茂`。

### 6.2 打 libPVZ2.so 补丁

仅验证过 **返茂 1.4.2 arm64-v8a**。其他版本偏移会变，不能盲打。

```powershell
python localization\scripts\patch_cdn_lawnstrings_skip.py `
  work\apk_decoded\lib\arm64-v8a\libPVZ2.so
```

补丁逻辑：

1. **Untar（`0x16ad6c8`）**：成员名以 `LawnStrings-` 开头 → 写到 `._cdn_lawn_skip`，不覆盖真正的 `LawnStrings-en-us.rton`  
2. **Applying（`0xd17c30`）**：文件名以 `LawnStrings-` 开头 → 跳过写盘  

脚本会在首次运行时备份为 `libPVZ2.so.bak_pre_lawnskip`。

### 6.2.1 图鉴越翻越缺字 / 货币花屏（PrimeGlyphCache）

全中文图鉴会把 Sexy/EAText 的固定 **glyph atlas** 塞满。满载时引擎打 WARNING「no place to put this glyph」，新字变空白；杀进程又好。这和对话 FontName（有没有 CJK 字面）是两层问题。

**做法**：在 `BuildPart` 满载分支清 atlas 并重试一次（`patch_glyph_cache_clear.py`，`reproduce_zh_apk` 已含）。必须对 **全局 glyph mesh**（`0x16b706c`）调用 clear（`0x16b7e7c`），以 bump 全局世代号 `+0x24`；HUD（钻石/金币）靠该世代与控件快照 `+0x100` 比对后重建。若只清当前局部 mesh，会出现「缺字好转、货币/错字花屏」。

半路重试跳回循环头（`0x16b65e0`）前还必须：`mov w26, wzr` 并 `str wzr, [x19, #0x44]`（对齐入口的绘制计数清零）。只清 atlas/游标而不清 `w26` 时，常见现象是「货币正常、图鉴长描述叠字」。

```powershell
# 顺序：先 CDN（6.2），再 Glyph。可从.bak_pre_glyphclear 重打 Glyph。
python localization\scripts\patch_glyph_cache_clear.py `
  work\apk_decoded\lib\arm64-v8a\libPVZ2.so
```

Cave 在 CDN 洞之后（`0x1B52980`），运行时**禁止写 RX**（retry 标志用 BuildPart 栈 `[sp,#0x70]`）。备份：`libPVZ2.so.bak_pre_glyphclear`。

### 6.3 重打包并签名

```powershell
apktool b work\apk_decoded -o F:\sen_work\PvZ2_RFL_zh_unsigned.apk

$bt = "$env:LOCALAPPDATA\Android\Sdk\build-tools\35.0.0"
& "$bt\zipalign.exe" -f -p 4 F:\sen_work\PvZ2_RFL_zh_unsigned.apk F:\sen_work\PvZ2_RFL_zh_aligned.apk
& "$bt\apksigner.bat" sign --ks F:\sen_work\debug.keystore --ks-key-alias androiddebugkey --ks-pass pass:android --key-pass pass:android --out F:\sen_work\PvZ2_Reflourished_1.4.2_zh.apk F:\sen_work\PvZ2_RFL_zh_aligned.apk
& "$bt\apksigner.bat" verify --verbose F:\sen_work\PvZ2_Reflourished_1.4.2_zh.apk
```

## 7. 安装与联网验证

### 7.0 单体 all-in-one APK（推荐给最终用户）

把汉化 APK、完整 OBB、CDN 中文种子打进**一个**可直接安装的 APK。首次启动由 `BootstrapActivity` 自动释放到官方路径，无需 SAI / 手拷 / adb。

**构建（开发者）：**

1. 确保 `work/apk_decoded` 已含 CDN SO 补丁，且 Manifest 启动项为 `com.ea.game.pvz2_rfl.zh.BootstrapActivity`
2. 准备 `F:\sen_work\main_schemeA_almanac.obb` 与现行 `LawnStrings-en-us.rton`（优先 `F:\sen_work\current\`）
3. 运行：

```powershell
python localization\scripts\build_allinone_apk.py
# 产出：F:\sen_work\PvZ2_Reflourished_1.4.2_zh_allinone.apk（约 1.3GB+）
```

脚本流程：`apktool b`（不含大文件）→ 以 **ZIP_STORED** 注入 `assets/obb/…`、`assets/cdn/LawnStrings-en-us.rton`、`assets/pvz2_zh_payload.version` → zipalign → apksigner。  
**不要**把 1.3GB OBB 拷进 `work/apk_decoded/assets`。

**用户安装：**

1. 卸载旧版同包名 `com.ea.game.pvz2_rfl`（签名不同无法覆盖装）
2. 系统安装器打开 `PvZ2_Reflourished_1.4.2_zh_allinone.apk`
3. 打开游戏：首次出现「正在准备/释放」进度（需约 1.3GB 空闲）；完成后进入标题屏

释放目标：

- `Android/obb/com.ea.game.pvz2_rfl/main.675.com.ea.game.pvz2_rfl.obb`
- 同目录 `obbVersion` 文本 **`1.4.2-r01`**（与 `OBBHelperJ.currentVersion` 一致；缺此文件首次会误弹下载）
- `Android/data/…/files/No_Backup/CDN.1.4.2/LawnStrings-*.rton`（en-us / zh-cn / zh-hans / zh-tw）

第二次启动若 payload 版本与文件长度匹配则跳过释放。部分设备对 **>1GB APK** 安装较慢或失败，属分发限制。

开发调试仍可用下面的分体 adb 流程（§7.1–7.2）。

### 7.1 安装（分体 / 开发）

```powershell
adb install -r F:\sen_work\PvZ2_Reflourished_1.4.2_zh.apk

adb push release_zh\main.675.com.ea.game.pvz2_rfl.obb /sdcard/Android/obb/com.ea.game.pvz2_rfl/main.675.com.ea.game.pvz2_rfl.obb
```

### 7.2 写入中文 CDN 文案（必做一次）

补丁只**阻止覆盖**，不会自动生成中文文件。需要先放入中文 RTON：

```powershell

```

目录不存在时先启动一次游戏，或手动 `mkdir`。  
**OBB 更新译文后，CDN 这份也要一起换**，否则联网仍显示旧译。

### 7.3 启动

```powershell
adb shell am force-stop com.ea.game.pvz2_rfl
adb shell am start -n com.ea.game.pvz2_rfl/com.popcap.PvZ2.PvZ2GameActivity
```

确认进程存活（PowerShell 勿用只读变量 `$PID`）：


### 7.4 成功标准

1. **联网**打开标题屏，主按钮为「开始」而非 `Start`  
2. 进关 / 剧情：对话为完整汉字（无 `_`）；抽查「欢迎来到古埃及」「与此同时」字体一致  
3. 图鉴抽查植物描述（如土豆地雷）与参考译一致  
4. 强制 CDN 刷新后（删掉 `Quests.rton` 等再启动），`Quests` 会恢复，但：

```powershell

```

中文文件 MD5 **不变**；同目录可能出现 `._cdn_lawn_skip`（英文被丢到这里）。

5. logcat：

```powershell
adb logcat -s PvZ2Debug:D
```

可见 `CDN:: Extracting TAR` / `Applying file`；其中 `Applying file LawnStrings-en-us.rton` 耗时应接近 0。

断网也能中文：说明 OBB/CDN 本地文件有效。

## 8. 原理简述（给要改版/移植的人）

```text
启动 → ContentDownloader
        ↓
   下载 main.tar（CDN: reflourished.ducnguyen.org 一类地址在 libRFLib）
        ↓
   Extracting TAR  (libPVZ2: 0x141d590 → 0x16ad6c8 → 0x16afaf8)  ← 真正写 LawnStrings
        ↓
   Applying file… (0xd17c30 → 0xd18174 / 0xd187a8)                 ← 后处理
        ↓
   UI 通过格式串 "LawnStrings-%s" 加载 CDN.1.4.2 下的 locale 文件

图鉴植物属性：
   Packages 内 0x90 ASCII 字面量（如 ZEN GARDEN BOOST）
        ↓ 错误：直接写 UTF-8 中文 → 横线
        ↓ 正确：等长 [STAT_…] + LawnStrings 中文（§5.1.1）
   运行时查表优先走 CDN LawnStrings-en-us.rton

对话气泡：
   NPCDataSheet.FontName → typefaces（BRIANNE/PICO/…）→ LoadingFonts TTF
        ↓
   拉丁无 CJK → 横杠
   解决（发布）：LoadingFonts --full-coverage 多风格 CJK
   解决（一键/保底）：FontName → BLACK_*（fbUsv8C5eI）
```

补丁对准 **1.4.2 arm64** 固定偏移；换版本需重新找：

- 字符串 `LawnStrings-%s`、`Applying file`、`Extracting TAR file`  
- untar 循环里 `bl 0x16af178`（取成员名）之后  
- apply 循环里取文件名之后、按 type 分发之前  
- Packages / LoadingFonts / NPCDataSheet 在 RSB 中的新偏移

## 9. 常见问题（含实测踩坑）

| 现象 | 原因 | 处理 |
|------|------|------|
| 安装后仍全英文 | CDN 英文覆盖 / 未推中文 RTON | 推送中文 `LawnStrings-en-us.rton` + 确认 SO 补丁 |
| 仅断网中文 | 未打 CDN 补丁 | 重新 patch `libPVZ2.so` 并重签安装 |
| **菜单中文、对话横杠** | 对话字体无 CJK | 跑 `patch_dialogue_font_compat` / `reproduce_zh` |
| **打开就闪退** | Packages zstd 用了 single-segment | Packages 用 streaming L19、desc=`0x80` |
| **打开就闪退** | LoadingFonts `usize` 拉长 / 名池整表重写 | 固定 `0x4B7000`；见 §5.4 |
| **打开就闪退** | Packages 槽写错 | `0xCF55000`、长度 `3522560` |
| 游戏重新下官方 OBB | obb 文件名/版本不匹配 | 使用 `main.675.…` 且版本与 APK 一致 |
| 脚本路径报错 | 路径含空格、中文 | 工作文件放到 `F:\sen_work` 等短路径 |
| `patch_cdn_*.py` 报 unexpected bytes | SO 版本不对或已补丁 | 用原版 1.4.2 的 so，或从 `.bak_pre_lawnskip` 恢复 |
| 清了 CDN 目录又变英文 | 没有中文种子文件 | 再 push 一次中文 RTON；补丁不会自动注入译文 |
| 参考译没进游戏（如「砰隆」） | 只改了 JSON 未 encode/回封，或 CDN 仍是旧 RTON | 重新 encode → 回封 OBB → **同步推 CDN** |
| 只改了 OBB、CDN 仍旧译 | 两套文案不同步 | OBB 与 `LawnStrings-en-us.rton` 用同一份 RTON |
| **图鉴属性仍英文** | Packages 字面量未改 | 按 **§5.1.1** 打 `--stat-refs` |
| **关卡目标标题中文、正文英文** | Description 为 `0x90` 英文句 | 按 **§5.1.2** 打 `[OBJ_…]` 并同步 CDN |
| **图鉴属性横线 / `_`** | 中文直接写入了 `0x90` 槽 | 改用 `[STAT_…]` + LawnStrings，勿塞 UTF-8 |
| **`<Missing STAT_…>`** | CDN LawnStrings 缺新键 / 未强停 | 推含新键的 RTON 到 CDN，**force-stop** 再开 |
| **正文变回机翻** | encode 用了归档机翻底 | 只用现行 `LawnStrings_zh.json` / `current/` 再 encode |
| **`生命值_3` 等** | `×` 等符号缺字形 | 译文改用 `x3` / `3倍` 等 ASCII/常用汉字 |
| 推了 CDN 仍见旧文案 | 进程缓存未刷新 | `adb shell am force-stop com.ea.game.pvz2_rfl` 后重开 |
| Activity 不存在 | 启动组件名写错 | 用 `com.popcap.PvZ2.PvZ2GameActivity` |
| 32 位设备 | 本补丁只改了 arm64-v8a | 需对 `armeabi-v7a` 另找偏移再打 |

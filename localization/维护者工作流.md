## 1. 完整汉化要动哪些层（经验结论）

只改 LawnStrings **不够**。1.4.2 实测完整效果需要：

| 层 | 作用 | 本仓库做法 |
|----|------|------------|
| OBB `Packages` ×6 LawnStrings | 离线文案 | `reproduce_zh` / `repack_obb_packages` |
| Packages 图鉴属性 `0x90` 字面量 | 否则图鉴属性仍英文 | 等长 `[STAT_…]` + 键进 LawnStrings |
| Packages 关卡目标 Description | 否则目标正文仍英文 | 等长 `[OBJ_…]` + 键进 LawnStrings |
| LoadingFonts 方案 A | 否则对话横杠 | `--full-coverage`：独立保留文楷（戴夫）、像素字（Pico12）、马克笔（脚本脸）；其余对话脸 alias 到 UI 黑体（**唯一路径**） |
| CDN `LawnStrings-en-us.rton` | 联网优先读这里 | 与 OBB **同一份** RTON |
| APK `libPVZ2.so` | 阻止英文 CDN 覆盖文案 | CDN skip + Glyph cache clear |

硬规则：

- **禁止**把 UTF-8 中文直接塞进 Packages `0x90` 槽（图鉴横线）
- LoadingFonts **`usize` 固定 `0x4B7000`，禁止增大**
- Packages zstd 必须 streaming、Frame Descriptor **`0x80`**（single-segment 易闪退）
- 换游戏版本后 SO 偏移 / OBB 槽位全部作废，需重找

### 1.4.2 关键常量

| 项 | 值 |
|----|-----|
| OBB 名 | `main.675.com.ea.game.pvz2_rfl.obb` |
| Packages 偏移 / `csize` | `0xCF55000` / `3522560` |
| LoadingFonts 槽 / `usize` | `0xB17B000` / `0x4B7000` |
| LawnStrings 单槽 | `2666496`（×6） |
| `obbVersion` | `1.4.2-r01` |
| 常量代码 | `scripts/obb_layout_142.py` |

## 2. 标准发版流程（推荐按这个走）

仓库根目录执行。PowerShell **不要**用 `&&`。

### A. 只改了译文（不动 Packages 结构）

```powershell
# 1) 编辑 localization/LawnStrings_zh.json
python localization\scripts\build_zh_rton.py
# → localization/LawnStrings_zh.rton、current/、release_zh/LawnStrings-en-us.rton
```

然后：

- **分体调试**：把新 RTON 推进手机 CDN，并（若 OBB 内嵌文案也要同步）用最新 RTON 重跑 OBB 注入；或  
- **出一体包**：先有最新汉化 OBB，再跑 §2-C。

**硬性禁令（2026-11-10）：**

- **禁止**把「仅 Packages 重注 LawnStrings、未重跑 LoadingFonts 方案 A」的 OBB 直接 `adb push` / 拷进 `release_zh` / 打一体包。  
- 对话横杠、开局提示横杠、或「只剩 BLACK 黑体」= **LoadingFonts 半残**，不是 RTON 问题。  
- 任何准备发版或推设备的 OBB，先跑：

```powershell
python localization\scripts\verify_obb_scheme_a.py .\out_zh\main.675.com.ea.game.pvz2_rfl.obb
# 必须 OK；FAIL 则重新 reproduce_zh，不要推半残包
```

### B. 从原版 OBB 整条复刻（译文 + STAT/OBJ + 多字体）

准备：

- 原版 `main.675….obb`（LoadingFonts 须为 stock 布局，不要拿半残汉化 OBB 当底座）
- `fonts_cjk`：用 `build_dialogue_cjk_fonts.py` **不要加 `--compact`**（全量 LawnStrings 字符集）。`--compact` 仅调试体积，发版会缺字横杠。
- LoadingFonts 解压上限固定 `0x4B7000`（约 4.72 MiB）。`Pico12` 必须单独打包像素字（`fusion-pixel`），缺字只从黑体补字形，不能整脸换成 UI。

**硬性禁令（2026-11-11，像素字与补字）：**

- **禁止**把 `PICO12__.TTF` alias 到 UI，也禁止用思源黑体整份覆盖 `Pico12.ttf`。潘妮的 FontName 就是 Pico12；全量构建后若 Pico 文件和 UI 同源，只是少存一份重复黑体，游戏里像素字会消失。体积紧也不能动这张脸。
- 像素字缺字只能把缺的字形描进 `fusion-pixel` 子集。描入后必须同时补 `vmtx`，并把 `vhea.numberOfVMetrics` 设成新的字形数。只改 `maxp` / `hmtx` 会让 `vmtx` 比字形数短（每缺一条竖排度量，表就短 2 字节）。这种 TTF 用 fontTools 打开就会报 `not enough 'vmtx' table data`。
- 装进 OBB 后的表现不是横杠，而是打开约 2 秒闪退：`PvZ2Debug` 打出 `Loading main RSB` 后，GL 线程 `SIGABRT`，debuggerd 常只有 `failed to write crash info: Bad address`，没有可用栈。
- 打包前先确认字体能读：

```powershell
python -c "from fontTools.ttLib import TTFont; f=TTFont(r'F:\sen_work\fonts_cjk\Pico12.ttf'); f.getGlyphSet(); print('pico ok', f['maxp'].numGlyphs, f['vhea'].numberOfVMetrics)"
```

- 一体包的 `BootstrapActivity` 在「payload 版本相同、外置 OBB 大小与包内资源相同、`obbVersion` 仍是 `1.4.2-r01`」时不会重新解压。只改了 OBB 内容、文件大小却没变时，必须先删掉手机上的 `main.675….obb` 再启动，或改 payload 版本字符串，否则手机继续用旧的坏包。

```powershell
python localization\scripts\reproduce_zh.py `
  --obb <原版.obb> `
  --out-dir .\out_zh `
  --fonts-dir <fonts_cjk>

python localization\scripts\verify_obb_scheme_a.py .\out_zh\main.675.com.ea.game.pvz2_rfl.obb

# 可选 GUI（输出默认 out_zh）
python localization\scripts\reproduce_zh_gui.py
```

产出：`out_zh/main.675….obb`、`LawnStrings-en-us.rton`、`obbVersion`。

流水线摘要：抽 Packages → 编 RTON → STAT → OBJ → 再编 RTON → 注入×6（保留原 FontName）→ LoadingFonts full-coverage → 写回。

### C. 汉化 APK（CDN skip + Glyph）

```powershell
python localization\scripts\reproduce_zh_apk.py `
  --apk "<原版返茂 1.4.2.apk>" `
  --out-dir .\out_zh
```

产出：`out_zh/PvZ2_Reflourished_1.4.2_zh.apk`（keystore 默认同目录自动生成）。

### D. 打一体 all-in-one（给玩家的最终包）

前置：

1. `work/apk_decoded` 已含 CDN/Glyph 补丁，且入口为 `BootstrapActivity`
2. 汉化 OBB 在 `out_zh/` 或 `release_zh/`（`main.675….obb`）
3. RTON：优先 `release_zh/LawnStrings-en-us.rton`
4. `release_zh/debug.keystore`（或 `--keystore`）

```powershell
python localization\scripts\verify_obb_scheme_a.py .\out_zh\main.675.com.ea.game.pvz2_rfl.obb

# 建议先把复刻产物拷进 release_zh，便于默认路径命中
Copy-Item .\out_zh\main.675.com.ea.game.pvz2_rfl.obb .\release_zh\ -Force
Copy-Item .\out_zh\LawnStrings-en-us.rton .\release_zh\ -Force
Copy-Item .\out_zh\obbVersion .\release_zh\ -Force

python localization\scripts\build_allinone_apk.py
# 默认产出：release_zh\PvZ2_Reflourished_1.4.2_zh_allinone.apk
# 脚本会再次 verify_obb_scheme_a；半残字体会直接中止
```

要点：

- 脚本 `apktool b` 小包 → **ZIP_STORED** 注入 OBB/RTON/version → zipalign → 签名  
- **不要**把 1.3GB OBB 放进 `work/apk_decoded/assets`  
- 一体包内嵌的 OBB 必须是完整方案 A（见上）

发版：把 all-in-one（及可选分体）挂到 GitHub Releases；玩家文档指向 [用户安装.md](../用户安装.md)。

## 3. 分体 adb 调试（我们自测用）

```powershell
# 推 OBB 前必须先通过方案 A 门禁
python localization\scripts\verify_obb_scheme_a.py .\out_zh\main.675.com.ea.game.pvz2_rfl.obb

adb install -r .\out_zh\PvZ2_Reflourished_1.4.2_zh.apk
adb push .\out_zh\main.675.com.ea.game.pvz2_rfl.obb /sdcard/Android/obb/com.ea.game.pvz2_rfl/main.675.com.ea.game.pvz2_rfl.obb
adb push .\out_zh\obbVersion /sdcard/Android/obb/com.ea.game.pvz2_rfl/obbVersion
adb push .\out_zh\LawnStrings-en-us.rton /sdcard/Android/data/com.ea.game.pvz2_rfl/files/No_Backup/CDN.1.4.2/LawnStrings-en-us.rton
adb shell am force-stop com.ea.game.pvz2_rfl
adb shell am start -n com.ea.game.pvz2_rfl/com.popcap.PvZ2.PvZ2GameActivity
```

一体包自测：安装后**从桌面图标**开（走 Bootstrap 释放），不要只 `am start` 游戏主 Activity 跳过释放。

### 验收清单

- [ ] `verify_obb_scheme_a.py` 对将推送的 OBB 为 **OK**
- [ ] 联网标题「开始」
- [ ] 对话汉字、分角色风格正常（戴夫≠全 BLACK；潘妮是像素字，且无横杠）
- [ ] `Pico12.ttf` 能被 fontTools `getGlyphSet()` 打开（补字后 `vmtx` 与字形数一致）
- [ ] 开局前加载/提示汉字正常（非横杠）
- [ ] 图鉴属性 / 关卡目标正文中文（抽查）
- [ ] CDN 刷新后 `LawnStrings-en-us.rton` MD5 不变；可有 `._cdn_lawn_skip`
- [ ] logcat 里 `Applying file LawnStrings-en-us.rton` 接近 0 耗时

## 4. 手工手术（一键不够时）

一键脚本盖住 90% 发版。需要定点修时：

| 需求 | 脚本 |
|------|------|
| 抽/写 Packages 槽 | `obb_layout_142.py extract\|write` |
| 只换 6× LawnStrings | `repack_obb_packages.py` |
| 图鉴属性字面量 | `patch_packages_almanac_literals.py --stat-refs` |
| 关卡目标字面量 | `patch_packages_objective_literals.py` |
| LoadingFonts 全覆盖 | `patch_loadingfonts_append.py --full-coverage` |
| 生成 fonts_cjk | `build_dialogue_cjk_fonts.py` |
| 仅 CDN / Glyph SO | `patch_cdn_lawnstrings_skip.py` / `patch_glyph_cache_clear.py` |

顺序经验：Packages 先保留原 FontName → 写回底座 OBB → 再打 LoadingFonts。  
**勿用** `rebuild_loadingfonts_rsg.py` 发版（整表重写易闪退）。

活动关 CDN levels 里的英文 Description 会被联网重拉盖掉，**不进正式管线**；正式包保证 OBB 本地关 `[OBJ_…]`。

## 5. 踩坑速查（我们自己翻）

| 现象 | 原因 / 处理 |
|------|-------------|
| 菜单中文、对话横杠 | 未打方案 A LoadingFonts，或 fonts_cjk 字符集不够 |
| 潘妮变成黑体 | `Pico12` 被 alias 到 UI，或整脸换成了思源黑体。必须独立打包 `fusion-pixel` |
| 打开约 2 秒闪退，`Loading main RSB` 后 `SIGABRT` | 像素字补字时没延长 `vmtx`。先 `getGlyphSet()` 确认，再重打 OBB；一体包若版本和文件大小都没变，先删手机上的 OBB 再启动 |
| 图鉴属性仍英文 | 未打 `[STAT_…]` |
| 目标标题中文、正文英文 | 未打 `[OBJ_…]` |
| 图鉴属性横线 | 中文塞进了 `0x90`；改回等长键 + LawnStrings |
| `<Missing STAT_/OBJ_…>` | CDN RTON 缺新键；推新文件后 **force-stop** |
| 开局闪退 | Packages zstd 非 `0x80` / 槽长错 / LoadingFonts `usize` 被拉长 |
| 联网回英文 | APK 无 CDN skip，或没推中文 RTON |
| 图鉴越翻越缺字、货币花屏 | 需 Glyph cache clear（`reproduce_zh_apk` 已含） |
| 改了 JSON 游戏仍旧译 | 没 `build_zh_rton` / 没回封 OBB / CDN 仍旧文件 |
| `生命值_3` | 译文里的 `×` 等符号缺字形 → 改用 `x3` / `3倍` |
| SO patch unexpected bytes | 版本不对或已打过；从 `.bak_pre_*` 恢复 |

原理骨架（换版本时重找偏移）：

```text
CDN tar → Untar / Applying（跳过 LawnStrings-*）
图鉴：Packages 0x90 字面量 → [STAT_/OBJ_] → CDN LawnStrings 查表
对话：FontName → LoadingFonts TTF（方案 A：文楷 / Pico 像素 / 马克笔独立，其余脸 alias 到 UI）
```

## 8. 明确不做 / 已知残留（记录在案）

### 8.1 旅行日志「公路广告牌」——放弃汉化（2026-11-06）

**现象**：Travel Log 游客陷阱地图上，岛屿路牌仍显示英文（如 `NOW ENTERING` + `Mission Imp-possible` / `Classic Quests` 等）。

**结论**：

| 项 | 事实 |
|----|------|
| LawnStrings | 改文案**无效**。`Now Entering` / `Classic Quests` 等甚至不在表内；部分标题虽有 `EPIC_QUEST_*_TITLE` 中文，招牌不读这些键 |
| 资源形态 | WorldData `m_eventType=island` + `m_imageID`；文字烤在岛屿/节点贴图（或 PAM）里 |
| 引擎路径 | 逻辑在 `libPVZ2.so`（`%s_ISLAND%d`、`EffectAnimRig_IslandNode`）；Java/JADX 看不到 |
| 曾排除 | `IMAGE_UI_EVENT_PANELS_*` / ThymedEvents `ISLAND1` **不是**这些公路牌 |

**放弃原因**：要汉化需按 `m_imageID` 重绘贴图并 ETC2 回包，或改 SO 叠字；投入大、工具链不齐，**收益不值**。后续不要再为招牌开 LawnStrings / EventPanels 图集工具分支。

**玩家侧**：任务列表、史诗任务 UI、世界名等字符串层已汉化；仅地图装饰路牌保持英文。

### 8.2 其它已知「看起来像没汉化」但属另一类问题

| 现象 | 归类 | 是否值得再做 |
|------|------|----------------|
| 与 EN 完全相同的 URL / 资源 ID | 故意保留 | 不做 |
| 部分梗对话外文/乱码/Base64 | 原版梗或未译叙事 | 按活动优先级选做 |
| 装扮/图鉴专名偶发英文 | 锁表与润色 | 低优先抽查 |

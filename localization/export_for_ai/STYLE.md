# PvZ2 Reflourished 汉化风格（冻结）

## 专名（权威）

- **第一权威**：`localization/参考翻译/utf8/LawnStrings-ParaTranz.json`（原版/社区 PvZ2 汉化，非返茂专表）。
- **现行成稿**：`localization/LawnStrings_zh.json`（唯一启用；改词请改这里）。
- 旧机翻术语表已归档：`localization/archive/machine_translation/scripts/glossary_*.py`（**勿再整库套用**）。
- 示例（以参考/现行为准）：上古埃及、狂野西部、炫光魔音游、冷却时间、阳光消耗、生命值、潘妮（勿写「朋朋」）等。
- **僵尸**（Zombie 通称）：一律写「僵尸」；勿写「丧尸」。
- **戴夫**（Crazy Dave / Dave / David 称谓）：对白一律写「戴夫」；勿写「大卫」。可与「用户戴夫」并存。
- **农历新年**（`Lunar Zoo Year` / `Lunar New Year` 活动名）：统一写「农历新年」；勿写「笼笠新年」「月球动物园」「农历动物园年」。ParaTranz「笼笠新年」不作权威。
- **情尸节**（`Valenbrainz`）：统一写「情尸节」；勿写 Valenbrainz / 瓦伦布莱兹 / 把活动名误写成「情人节」。
- **僵企**（`ZCorp`；活动名「僵企入侵」）：统一写「僵企」；法人全称「僵企股份有限公司」；勿写「Z 公司」「僵企 Incorporated」。
- **僵伯特**（`Zombert` / Zombert Bartholomew Zomboss）：一律写「僵伯特」；超级形态写「超级僵伯特」。勿写「赞伯特」「佐伯特」或裸留英文 Zombert（引擎标签 `{SAY:zombert}` 除外）。
- **迷失探险家僵尸**（`Lost Explorer Zombie` / `ZOMBIE_LOSTCITY_EXPLORER`）：Lost＝迷路/迷失，与 FLAVOR「他不再迷失」对应；勿写「丢失探险家」。埃及形态仍为「探险家僵尸」。
- **暗影家族**（`The Shadow Family`）：成就名 / 现代挑战花瓶关 / 教室讲解统一「暗影家族」；勿写「影子家族」。暗影植物机制用语优先「暗影」（非光学「影子」）。
- **被俘植物**（`captured plants`）：僵尸关押、待营救的植物；勿写「捕获的植物」。关卡目标里的 endangered 保护关仍可用「濒危植物」。
- **僵尸幸运星**（`Luck O' The Zombie`）：统一写「僵尸幸运星」；勿写缺「星」的「僵尸幸运」。
- **后院脑碗**（`Backyard Brain Bowl` / Sportzball 活动名）：统一写「后院脑碗」；勿写「后院脑力碗」「后院脑子杯」。僵尸短名 Lawnbowl 用「草坪碗」。
- **亨特里亚**（`Hunterria`）：对白统一中文，勿中英混跳；勿写「亨特利亚」。
- **暖春节**（`The Springening`）：统一写「暖春节」；勿用「春暖花开/春天」代替活动名。
- **食物大战**（`Food Fight`）：统一写「食物大战」。
- **叶绿素**（Plant Food）：勿写「植物性食物」。火龙草（Snapdragon）勿误译龙舌兰。
- **盛宴节**（`Feastivus`）：统一写「盛宴节」。
- **末日草坪**（`Lawn of Doom` / Halloween 活动壳）：统一写「末日草坪」；对白可提万圣节氛围，活动名勿另造。
- **现代年华**（`Modern Day`）：世界名统一写「现代年华」（随 ParaTranz）；返访套话勿用公文「您」。
- **狮身终结者僵尸机器人**（`Zombot Sphinx-inator`）：对白勿留英文机名。
- **蒸汽时代**植物：法尼拉、炼金百合、莲藕、西番莲机械师（勿留 Fanilla 等英文）。
- **昏暗嘉年华**：双胞胎小鬼、惊吓盒、愤怒玩具箱、大力士巨人僵尸；爆气球花 / 焦糖爆米花投手 / 脆薯片。

- **节日合集对白**（`NARRATIVE_HOLIDAY*`）：小鬼僵尸有限（Impfinity）；#蛋糕坦克；多重性；Slamrock 巨人僵尸（名锁保留英文前缀）；奶奶的祖普汤 / 祖普汤（Zoup）；僵经济（Zomconomy）；Brainz ZDN 可留品牌英文。
- **强酸柠檬**（`Acid Lemon` / `ACIDLEMON`）：对白与图鉴统一「强酸柠檬」；勿写「酸液柠檬」。

- **LTE 对白**：潘妮「我检测到/正在扫描」优先「读数显示/扫描中」；「正确，用户戴夫」→「没错，用户戴夫」。公文「您」一律改「你」（含资讯小姐采访口吻）。僵亿万（Zombillion）；真厂房可保留「工厂」。
- **LTE 优化/抽查范围**：无对应 `LTE_REPLAY_{活动}_{年}` 的往届限时活动 **Pass**（不改优、不进随机审阅）。白名单与工具见 [`lte_qa_scope.md`](lte_qa_scope.md)。

## 语气

- **UI / 按钮 / 提示**：短、直、无多余语气词。
- **剧情**：保留角色口吻。Crazy Dave（crazydave）略疯癫口语；Penny / Winnie 偏冷静书面。不要过度网络烂梗。
- **图鉴（宝开语）**：见 [`almanac/BAOKAI.md`](almanac/BAOKAI.md)。短名冻结于 [`almanac/almanac_name_lock.json`](almanac/almanac_name_lock.json)；主攻 `{FLAVOR}`，HEADER 轻宝开，TOOLTIP 功能句。

## 必须原样保留

- 占位符：`%s` `%d` `%1$s` `{0}` `{1}` `#` 等（数量与顺序不变）。
- 对话 / 演出宏：`{SAY:…}` `{PLAYFUL:…}` `{EXCITED:…}` `{TIRED:…}` `{NPC_ENTER:…}` 以及 `{KEYWORD}` `{STAT}` `{FLAVOR}` 等富文本标记。
- 换行：与英文对齐；参考里的 `/r\n` 导入时规范为 `\r\n`。
- 技术值：URL、`@@BADCACHE:`、`.RTON` / `.json` 文件名——不译。

## 合并优先级（文案）

1. **P0**：同 key 且参考 `original` ≡ 返茂英文 → 直接采用参考译文。  
2. **P1**：英文相同、key 不同（如 `achieve_*` ↔ `ACHIEVE_*`）→ 按英文映射写入返茂 key。  
3. **P2**（`merge_ref_p2.py`）：同 key 但英文已变 →  
   - 琐差异（大小写 / 标点 / 空白）：可覆盖；  
   - 图鉴 `*_DESCRIPTION`：**保留返茂中文数值前缀**（`{KEYWORD}`/`{STAT}`），仅替换参考 `{FLAVOR}`；  
   - HEADER 英文缩短而参考更完整：可采用参考全文；  
   - 剧情等英文重写过大：**不自动合并**。  
4. 参考没有的返茂独有句：保留现译，专名以新 glossary 为准。

## 禁止

- 中英夹杂整句（如「向日葵 are very important…」）。
- 翻译或删改宏标签本身。
- 用已废弃的旧官中 glossary 回灌，把参考译名改回去。
- 用短语表对已整句参考译文再次全文替换污染。

# 一键复刻最短路径（1.4.2）

从原版资源生成**汉化 OBB + CDN RTON**，以及（可选）**含 CDN skip 的汉化 APK**。完整联网中文需要两者配对。

## 环境

**OBB 流水线**

- Python 3.10+
- `pip install zstandard`
- 本仓库 clone（含 `localization/LawnStrings_zh.json` 与键表）
- 原版 `main.675.com.ea.game.pvz2_rfl.obb`（约 1.3GB，不进 Git）

可选：`localization/LawnStrings_en.json`（有则 OBJ 表更全；缺则走 `EXTRA_ZH`）。

**APK 流水线（额外）**

- `apktool`（如 `choco install apktool`）
- JDK（`keytool` 在 PATH）
- Android SDK build-tools（`zipalign` / `apksigner`，常见于 `%LOCALAPPDATA%\Android\Sdk\build-tools`）
- 原版返茂 1.4.2 APK（arm64）

## OBB：一条命令 / GUI

```powershell
cd F:\othergit\Reverse Engineer Anything
python localization\scripts\reproduce_zh.py `
  --obb F:\path\to\main.675.com.ea.game.pvz2_rfl.obb `
  --out-dir F:\out_zh
```

```powershell
python localization\scripts\reproduce_zh_gui.py
```

流水线：抽 Packages → 编 RTON → STAT → OBJ → 再编 RTON → 注入 LawnStrings×6 → BLACK 对话字体 → 写回 OBB + `obbVersion`。

| 文件 | 用途 |
|------|------|
| `out-dir/main.675.com.ea.game.pvz2_rfl.obb` | 汉化 Packages |
| `out-dir/LawnStrings-en-us.rton` | 推 CDN |
| `out-dir/obbVersion` | 内容 `1.4.2-r01` |
| `out-dir/work/` | 中间 section / 新键快照 |

手工抽写槽：`python localization/scripts/obb_layout_142.py extract|write …`。

## APK：一档一键（CDN SO + 重签）

```powershell
python localization\scripts\reproduce_zh_apk.py `
  --apk "F:\path\to\PvZ2 Reflourished 1.4.2.apk" `
  --out-dir F:\out_zh
```

或在 GUI 中选原版 APK →「开始打 APK」（与 OBB 共用输出目录）。

流水线：`apktool d` → CDN lawnstrings skip → Glyph cache clear → `app_name` 中文 → `apktool b` → zipalign → apksigner。  
产出：`out-dir/PvZ2_Reflourished_1.4.2_zh.apk`（keystore 默认 `out-dir/debug.keystore`，自动生成）。

手工步骤与排错仍见 [汉化教程.md](./汉化教程.md) §6。

## 安装三件套

1. **汉化 APK**（本脚本或 Releases）→ 换签名需先卸载旧包  
2. **汉化 OBB** + `obbVersion` → `/sdcard/Android/obb/com.ea.game.pvz2_rfl/`  
3. **`LawnStrings-en-us.rton`** → `…/files/No_Backup/CDN.1.4.2/`

脚本 / GUI 可复制对应 `adb` 行。单体 all-in-one 仍用 `build_allinone_apk.py`（不在最短路径内）。

## 验收

- OBB Packages 槽为 zstd（`28 B5 2F FD`），长度 `3522560`
- CDN RTON 可 decode，含中文与 `STAT_` / `OBJ_` 键
- 汉化 APK：`apksigner verify` 通过；联网后中文不被英文 CDN 盖掉
- 标题「开始」、对话汉字

**对话字体两条线（不要混）：**

| 谁用 | 做法 |
|------|------|
| **你自己的发布包** | LoadingFonts **方案 A** `--full-coverage`（多风格字：戴夫文楷等），见教程 §5.2 |
| **一键复刻 / 外人最短路径** | `reproduce_zh` 默认 **BLACK_*** 映射（够用、零字体工程） |

本期 GUI **不**含：一键 all-in-one（仍用 `build_allinone_apk.py`）；一键也不自动打 `--full-coverage`（避免绑死本机 `fonts_cjk`）。
